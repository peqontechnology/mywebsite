GITHUB PAGES DEPLOYMENT
-----------------------
1. Open your GitHub repository: peqontechnology/mywebsite
2. Upload/replace ALL files from this package.
3. Make sure the assets folder is uploaded too:
   assets/logo.png
4. Go to Settings > Pages.
5. Source: Deploy from a branch
6. Branch: main
7. Folder: / (root)
8. Save.

IMPORTANT LOGO FIX
------------------
The logo file must be located exactly at:
assets/logo.png

Do not rename it to Logo.png, logo.PNG, etc.
